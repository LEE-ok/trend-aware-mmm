## 정적 출력과 경로 이식성

- `output: "export"`, `trailingSlash: true`, 이미지 최적화 서버 미사용 설정을 유지했습니다.
  6개 사용자 경로가 모두 정적으로 생성되었습니다.
- 최종 `out/`: 62개 파일, 1,744,510 bytes(약 1.66 MiB), 최대 파일 388,872 bytes.
  QA 캡처·소스 CSV·테스트·Python·trace는 `out/`에 포함되지 않습니다.
- 원본 CSV 헤더·행별 날짜, trace/CSV/모델 파일 확장자, 일반적인 비밀값 패턴,
  로컬 사용자 절대 경로를 검사하여 검출 사항이 없었습니다.
  패턴 검사는 모든 형태의 비밀값을 보장하는 검사가 아닙니다.
- `apps/web` 내부 import 경로의 대소문자 일치와 앱의 API/서버 액션 부재를 검사했습니다.
- 정적 출력 보정기는 Node의 `path`/파일 URL API를 사용합니다. 절대 Windows 경로에 의존하지 않습니다.
  중첩 Windows RSC 출력과 평면 Linux 형태를 임시 fixture로 검사했고 재실행도 동일했습니다.
- 현재 환경에 동작하는 Linux/WSL 배포판이나 Docker가 없어 **실제 Linux 빌드는 미검증**입니다.
  Vercel 빌드에서 재확인해야 하며 로컬 Windows 성공을 Linux 성공이라고 보고하지 않습니다.

## Vercel Hobby 설정안 — 아직 적용하지 않음

정적 HTML/CSS/JS로 동작하므로 서버리스 함수·DB·Python 서버·유료 API 없이 호스팅할 수 있는 구조입니다.
이는 코드 검토와 로컬 빌드에 따른 기술적 판단이며 Vercel 실배포 검증 결과는 아닙니다.
Hobby는 개인·비상업 용도와 무료 사용량 제한에 적합한 경우에만 사용합니다.
용도와 계정/저장소 권한은 실제 연결 전에 확인해야 합니다.

| 설정 | 준비 값 / 처리 |
|---|---|
| Git repository | LEE-ok/trend-aware-mmm |
| 대상 branch | feature/nextjs-dashboard; main 변경·merge 불필요 |
| Root Directory | `apps/web` |
| Framework Preset | Next.js |
| Node.js Version | 24.x (로컬 검증 버전 계열과 맞춤) |
| Install Command | `npm ci` (기존 package-lock 사용) |
| Build Command | **`npm run build`** (정적 출력 보정 단계까지 포함) |
| Output Directory | 정적 export `out`; 대시보드 감지값 확인, 필요 시 `out` 지정 |
| Include files outside root | 필요 없음; 비활성화 가능 |
| 앱 환경변수 / API 키 | 필요 없음 |
| Python / DB / Functions / Cron | 설정 불필요 |
| Image Optimization / SSR / ISR | 현재 사용하지 않음 |
| Analytics / 유료 통합 | 현재 필요 없음; 활성화하지 않음 |
| 도메인 | 기본 vercel.app으로 시작 가능; 유료 도메인 구매 불필요 |

Linux 빌드 설정에는 `npm.cmd`, `.venv\Scripts\...`, 로컬 절대 경로를 넣지 않습니다.
데이터 JSON은 미리 검증하여 저장한 파일을 사용하므로 배포 빌드에서 CSV export나 모델 실행을 하지 않습니다.
Git 연결·프로젝트 Import 자체가 배포를 시작할 수 있으므로 지금 실행하지 않았습니다.
새 vercel.json, CI 배포 파이프라인, 토큰도 추가하지 않았습니다.

공식 자료 확인:

- [Hobby plan](https://vercel.com/docs/plans/hobby): 개인·비상업 용도, 사용량 제한 초과 시 기능 이용 제한 가능.
- [Build 설정](https://vercel.com/docs/builds/configure-a-build): Root Directory와 빌드·설치·출력 설정.
- [Node.js 버전](https://vercel.com/docs/functions/runtimes/node-js/node-js-versions): 24.x 지원과 메이저 버전 선택.
- Next.js static export는 설치된 버전의 `node_modules/next/dist/docs/01-app/02-guides/static-exports.md`로 확인했습니다.
