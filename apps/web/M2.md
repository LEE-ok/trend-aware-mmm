# M2: 문서 기록 기반 시나리오·예산 최적화

`/scenarios/`는 기본·trend 모델의 S0와 S1~S4(각 5/10/15%p 이동)를 비교합니다.
`/optimization/`은 기본·trend·trend+운영 경계의 기대최적(pooled) 배분을 비교합니다.
기본 선택은 trend+운영 경계이며 DM 최소 5%, VIDDIG 최대 8.3%를 적용합니다.
정적 export, 기존 의존성 및 M1 공통 UI를 유지하며 API·DB를 추가하지 않습니다.

## 데이터 계약

- `data/mmm-results.json`: 2026-10-12 확정런 문서 기록만 포함합니다.
- 출처: `docs/scenario-results.md`, `docs/optimization.md`; S0 비중·이동 조건: `docs/scenario.md`.
- `provenance: document_recorded`, `trace_verified: false`입니다.
- `validation_status: passed`는 `validation_scope: document_values_only`에 한정됩니다.
  모델 재현성이나 trace 검증을 뜻하지 않습니다. 출처 파일 SHA-256을 보존합니다.
- 금액은 `hundred_million_usd`(억 USD), 기간은 13주 합계, 신용수준은 80%입니다.
  총예산은 16.20 million USD입니다.
- 비중은 퍼센트, 이동폭과 비중 차이는 %p입니다. S0는 최근 13주 비중으로,
  M1 전체 209주 비중과 다릅니다.
- S0의 시나리오 변화율은 문서의 대시를 `null`로 보존합니다.
  변화율과 paired 구간은 문서값을 유지하며 반올림 매출로 역산하지 않습니다.
- 운영 경계안의 비중 합계 99.9%는 문서 반올림 그대로 보존합니다.
  문서에 없는 운영 경계안의 비중 신용구간은 생성하지 않습니다.
- `interval`은 매출의 80% 신용구간, `paired_interval`은 같은 draw 간 증분의
  80% 신용구간입니다. 매출 구간의 양 끝을 빼서 증분 구간을 만들지 않습니다.
- 과거 점최적 오류 수치와 미기입 국소최적·하방위험 결과는 포함하지 않습니다.
  trace와 CSV를 읽거나 Bayesian 모델을 실행하지 않습니다.

## 재생성 및 검증

저장소 루트에서 기존 Python 환경을 사용합니다. 출력은 새 파일에만 저장합니다.
기존 스냅샷 덮어쓰기는 차단합니다. 검토용 새 파일을 만들려면:

```powershell
.venv\Scripts\python.exe -B apps/web/scripts/export_m2_data.py --output apps/web/.verification/m2-review.json
```

출력 상위 폴더는 먼저 준비해야 합니다. 스키마 검증 후 기록합니다.

```powershell
npm.cmd --prefix apps/web run typecheck
npm.cmd --prefix apps/web run lint
npm.cmd --prefix apps/web run build
.venv\Scripts\python.exe -B apps/web/scripts/test_m2_data.py
.venv\Scripts\python.exe -B apps/web/scripts/test_dashboard_data.py
```

M2 테스트는 26개 시나리오의 매출·구간·변화율·외삽, 최적화 3안의 모든 숫자,
S0 비중·운영 경계·기본 선택, 출처 해시, 엄격한 스키마와 정적 페이지 고지를 검사합니다.
M1 테스트는 기존 집계와 정적 출력의 원본 CSV·주간 기록 미포함을 재검사합니다.
