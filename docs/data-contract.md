# 주 단위 데이터 계약 v0.1
현재 입력: 단일 브랜드, 매출, 4개 채널, KRW.
업종·채널을 확정하면 코드와 계약을 함께 수정합니다.

| 컬럼 | 정의 |
|---|---|
| week | 주의 시작일, YYYY-MM-DD, 동일 요일, 오름차순 |
| revenue | 해당 주 총매출, 유한한 0 이상 숫자 |
| meta_spend | Meta 주간 지출 |
| google_spend | Google 주간 지출 |
| naver_spend | Naver 주간 지출 |
| influencer_spend | Influencer 주간 지출 |

모든 지출은 동일 통화의 유한한 0 이상 숫자입니다.
미집행은 0, 누락은 빈값입니다. 빈값을 자동으로 0으로 바꾸지 않습니다.
현재 검증기는 빈값·주차 누락을 오류로 보고합니다. 보간 정책은 추후 확정합니다.
추가 컬럼은 허용하지만 현재 검증 대상은 아닙니다.

sample CSV는 형식 확인을 위한 가상 4주 데이터입니다.
모델 학습, 성능 평가, 실제 예산 결정에는 사용할 수 없습니다.

트렌드 문서는 source_url, published_at, collected_at, category를 보관하고
과거 시점 평가에서는 당시 이용 가능했던 정보만 사용합니다.
